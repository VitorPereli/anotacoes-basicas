O que é o HTML?
O HTML (HyperText Markup Language ou Linguagem de Marcação de Hipertexto) é a base de qualquer página web. Ele não é uma linguagem de programação, mas sim uma linguagem de marcação: você usa "tags" (etiquetas) para dizer ao navegador como estruturar o conteúdo do site (textos, imagens, botões, etc.).

Principais Tags e Estruturas
<head> (Cabeçalho da Página)

Fica na parte superior do código HTML, antes do conteúdo visível.

Serve para guardar metadados: informações sobre a página que o usuário não vê diretamente na tela, como o título da aba do navegador (<title>), links para arquivos de estilo (<link rel="stylesheet">) e codificação de caracteres.

<body> (Corpo da Página)

É onde fica todo o conteúdo visível do seu site: textos, imagens, vídeos, formulários e botões. Tudo o que o usuário interage na tela está dentro do <body>.

<h1> (Título Principal)

Pertence à família de tags de títulos (<h1> até <h6>).

O <h1> é o título mais importante da página (geralmente usado apenas uma vez por página para o título principal). Os navegadores o exibem em destaque e ele é fundamental para o SEO (mecanismos de busca).

<p> (Parágrafo)

Usado para definir blocos de texto comum/parágrafos. O navegador automaticamente adiciona uma quebra de linha antes e depois de cada tag <p>.

<div> (Divisão ou Seção)

Uma tag genérica e invisível usada para agrupar outros elementos.

É amplamente utilizada para organizar o layout e aplicar estilos (com CSS) em blocos específicos da página (por exemplo, agrupar um título, uma imagem e um texto dentro de um card).

Página Estática vs. Página Dinâmica
A diferença entre elas está em como o conteúdo é entregue e alterado para o usuário:

Página Estática:

O conteúdo é fixo. O código HTML que está salvo no servidor é exatamente o mesmo que o navegador do usuário recebe e exibe.

Para alterar o texto ou a imagem de uma página estática, é preciso abrir o código-fonte, alterá-lo manualmente e reenviá-lo para o servidor.

Exemplo: Um site institucional simples ou um portfólio pessoal básico.

Página Dinâmica:

O conteúdo pode mudar em tempo real dependendo de quem acessa, do horário ou de ações do usuário.

Ela utiliza linguagens de programação no servidor (como Node.js, Python, PHP) e bancos de dados para gerar o HTML na hora em que a página é solicitada.

Exemplo: Redes sociais (Instagram, Twitter), sites de notícias, lojas virtuais (onde os produtos mudam) e plataformas de streaming (como Netflix).
